# HIKIKO SURVIVAL

Astroで作成した、ヒキコの文章とイラストのサイトです。

## HOME改装（site-renewal）

- 本人のイラストを薄く敷いた背景と紹介文
- PROFILEへの入口（既存の/about/）
- 右端から伸びるBLOG・ILLUSTRATION・ETC.のナビゲーション
- 記事タイトルの検索と、ETC.からのカテゴリー別絞り込み
- PC・スマートフォンの画面幅に対応したメニュー
- Contact・Privacy Policyへのリンク

既存の記事本文・お問い合わせ・プライバシーポリシーは維持しています。
改装はsite-renewalで確認し、mainへの反映前にプレビューを確認します。

## ローカルで確認

npm ciで必要な部品を準備し、npm run devでプレビューを起動します。
npm run buildで公開用ファイルを生成します。

## 確認結果

35ページの生成に成功。PC幅1440/1024、スマホ幅390/320で表示を確認。
記事検索、カテゴリー選択、モバイルメニュー、イラスト表示をブラウザーで確認しました。
